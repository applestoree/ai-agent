# Workflow: Output Validation

## Objective

Ensure the final response or artifact meets the request.

## Steps

1. Compare the result with each requirement.
2. Check completeness and consistency.
3. Verify links, file paths, and references when possible.
4. Confirm that requested formats are followed.
5. Identify unresolved issues.
6. Prepare a concise completion report.

## Completion Report

Include:

- Result
- Files or resources changed
- Verification performed
- Known limitations
- Remaining work, if any
