# Workflow: Input Analysis

## Objective

Convert the user's request into a clear task definition.

## Steps

1. Identify the requested outcome.
2. Extract explicit requirements.
3. Identify supplied files, data, and references.
4. Identify constraints and exclusions.
5. Check available context for prior decisions.
6. Identify missing information that blocks progress.
7. Determine whether clarification is necessary.

## Output

- Task summary
- Confirmed requirements
- Constraints
- Available inputs
- Blocking gaps, if any
- Proposed execution steps

Do not ask questions when the task can proceed safely and accurately with the available information.
