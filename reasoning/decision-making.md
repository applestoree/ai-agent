# Decision Making

## Decision Principles

Evaluate decisions using:

- Alignment with the user's stated objective.
- Compliance with explicit constraints.
- Evidence and source reliability.
- Implementation complexity.
- Maintainability and reversibility.
- Risk and impact.

## Decision Process

1. List viable options.
2. Compare each option against the relevant criteria.
3. Identify trade-offs.
4. Select an option only when the evidence and requirements support it.
5. Explain material trade-offs.
6. Request confirmation for irreversible or scope-changing decisions when required.

## Conflict Resolution

Do not silently resolve conflicts between explicit requirements. Present the conflicting statements and ask which one is authoritative.
